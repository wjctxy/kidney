是，**用原始第300帧会更适合画 `cortex_mask`**，因为 cortex ROI 本质是解剖/肾皮质范围，单帧原始 CEUS/灰度图更接近实际肾脏边界。`human_density_slow.png` 更适合看慢速轨迹聚集区，但它已经是 Step04 的重建密度图，会把血流结果反过来影响 ROI 判断。

但我建议这样分工：

- `cortex_mask`：用原始第300帧，或者更稳一点用第280-320帧平均图。
- `exclude_mask`：继续用 `human_density_slow.png` 或叠加 `human_density_rapid.png`，因为右侧竖直伪影、孤立亮点、主血管残留在密度图上更明显。

还有一个关键索引：你现在的 `stable_200_400` 是源视频第200到400帧，共201帧。所以**源视频第300帧 = `frames.npy` 的本地 index 100**，不是 index 300。

可以先生成第300帧 PNG：

```bash
.venv/bin/python - <<'PY'
import numpy as np
import matplotlib.pyplot as plt

frames = np.load("human_dcm/step00_preprocess/stable_200_400/frames.npy")
frame = frames[100]  # source frame 300 = 300 - 200

plt.imsave(
    "human_dcm/step00_preprocess/stable_200_400/source_frame_300.png",
    frame,
    cmap="gray"
)
PY
```

然后用它画 cortex：

```bash
python draw_step5_masks.py \
  --image human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --output masks/cortex_mask.npy \
  --overlay masks/cortex_mask_overlay.png \
  --mode cortex
```

画 exclude 还是建议用密度图：

```bash
python draw_step5_masks.py \
  --image human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --output masks/exclude_mask.npy \
  --overlay masks/exclude_mask_overlay.png \
  --mode exclude
```
