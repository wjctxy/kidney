
**人类链路接口**
```text
human_step01_bandpass.py
input:  frames.npy + metadata.json
output: human_filtered.npy

human_step02_gaussian_detect.py
input:  human_filtered.npy + metadata.json
output: human_detections.csv

human_step03_track_reconstruct.py
input:  human_detections.csv + metadata.json
output: human_tracks.csv
        human_low_speed_tracks.csv
        human_high_speed_tracks.csv
        density maps PNG
        metrics CSV/TXT
```

**大鼠链路接口**
```text
rat_step01_svd_filter.py
input:  frames.npy + metadata.json
output: rat_filtered.npy

input:  rat_filtered.npy + metadata.json
output: rat_detections.csv

rat_step03_track_reconstruct.py
input:  rat_detections.csv + metadata.json
output: rat_tracks.csv
        rat_low_speed_tracks.csv
        rat_high_speed_tracks.csv

        metrics CSV/TXT
```

**代码层面的规则**
- 核心算法函数接收 `np.ndarray`，返回 `np.ndarray` 或结构化记录。
- 脚本级 wrapper 负责读写 `.npy`、`.csv`、`.json`。
- PNG/MP4 只允许作为 `visualization output`，不能作为任何 step 的输入。
- 每个 step 文件开头写清楚：
  ```python
  """
  Input:
      frames.npy: float32 [T, H, W], normalized to [0, 1]
      metadata.json: fps, pixel size, frame time

  Output:
      ...
  """
  ```

下面按“数据在链路里如何流动”解释。核心原则是：**算法步骤之间只传 `.npy / .json / .csv` 这三类结构化数据；PNG/MP4 只作为给人看的结果，不再作为下一步输入。**

**共同入口**

两条链路都从同一类标准输入开始：

`frames.npy`

```python
frames: np.ndarray
shape = [T, H, W]
dtype = float32
range = 0.0 ~ 1.0
```

含义：

- `T`：时间帧数，例如一段 DICOM cine-loop 有多少帧。
- `H`：每帧图像高度，单位是像素。
- `W`：每帧图像宽度，单位是像素。
- 每个元素 `frames[t, y, x]` 表示第 `t` 帧中坐标 `(x, y)` 的归一化灰度强度。
- 这里必须是灰度图，不再混入 RGB、伪彩色、PNG 文件路径等格式。

`metadata.json`

```json
{
  "fps": 30.0,
  "frame_time_ms": 33.3333,
  "pixel_size_x": 0.0063787,
  "pixel_size_y": 0.0063787,
  "height": 512,
  "width": 512
}
```

含义：

- `fps`：帧率，每秒多少帧，用于滤波和速度计算。
- `frame_time_ms`：每帧间隔，毫秒。
- `pixel_size_x`：横向每个像素代表的实际距离。
- `pixel_size_y`：纵向每个像素代表的实际距离。
- `height` / `width`：图像尺寸，用来检查 `frames.npy` 和元数据是否匹配。

**人类链路**

人类链路对应 md 里的：

```text
时域带通滤波
→ 二维高斯滤波 / 局部峰值检测
→ 匈牙利追踪 / 速度分组 / 密度图与参数
```

`human_step01_bandpass.py`

输入：

```text
frames.npy
metadata.json
```

处理含义：

- 对每个空间位置 `(x, y)` 的时间序列 `I(x, y, t)` 做时域带通滤波。
- 去掉慢变化组织背景和高频随机噪声。
- 保留微泡通过时产生的中间频段动态变化。

输出：

```text
human_filtered.npy
```

格式：

```python
human_filtered: np.ndarray
shape = [T, H, W]
dtype = float32
range = 不强制，但建议仍归一化或保持可检测强度
```

含义：

- 仍然是一组时间帧。
- 每个像素值表示经过带通滤波后的动态信号强度。
- 这是后续检测微泡候选点的输入。

---

`human_step02_gaussian_detect.py`

输入：

```text
human_filtered.npy
metadata.json
```

处理含义：

- 对每一帧做二维高斯平滑。
- 用 `peak_local_max` 找局部亮斑峰值。
- 每个峰值视作一个微泡候选中心。
- 人类链路这里先以峰值坐标作为定位结果，不强制做径向对称亚像素定位。

输出：

```text
human_detections.csv
```

字段建议：

```text
frame_id,x_pixel,y_pixel,x_physical,y_physical,intensity,method
```

含义：

- `frame_id`：第几帧检测到该微泡。
- `x_pixel` / `y_pixel`：微泡中心在图像里的像素坐标。
- `x_physical` / `y_physical`：换算后的物理坐标。
- `intensity`：该位置的滤波后强度，用于后续质控。
- `method`：检测方法，例如 `gaussian_peak`。

一行代表：

```text
某一帧中的一个微泡候选点
```

---

`human_step03_track_reconstruct.py`

输入：

```text
human_detections.csv
metadata.json
```

处理含义：

1. 按 `frame_id` 把检测点分组。
2. 对相邻帧构造距离矩阵：
   ```text
   cost[i, j] = 第 t 帧第 i 个点 与 第 t+1 帧第 j 个点的距离
   ```
3. 用匈牙利算法做最小代价匹配。
4. 根据最大位移、最小轨迹长度等规则生成轨迹。
5. 根据轨迹速度划分高/低速。
6. 根据轨迹点累积生成血流密度图。
7. 计算 md 中提到的核心指标。

输出：

```text
human_tracks.csv
human_low_speed_tracks.csv
human_high_speed_tracks.csv
human_density_total.png
human_density_low_speed.png
human_density_high_speed.png
human_metrics.csv
human_summary.txt
```

其中 `human_tracks.csv` 字段：

```text
track_id,frame_id,time_s,x_pixel,y_pixel,x_physical,y_physical,velocity
```

含义：

- `track_id`：同一个微泡轨迹的编号。
- `frame_id`：该轨迹点来自第几帧。
- `time_s`：对应时间，单位秒。
- `x_pixel` / `y_pixel`：像素坐标。
- `x_physical` / `y_physical`：物理坐标。
- `velocity`：当前点相对上一个轨迹点的速度。

`human_low_speed_tracks.csv` / `human_high_speed_tracks.csv`：

- 结构和 `human_tracks.csv` 一样。
- 只是根据速度阈值把轨迹拆分成低速和高速。
- 这里才真正定义“高/低速”，不是在滤波阶段定义。

**大鼠链路**

大鼠链路对应 md 里的：

```text
SVD 滤波
→ 径向对称法亚像素定位
→ 匈牙利追踪 / 速度分组 / 密度图与参数
```

`rat_step01_svd_filter.py`

输入：

```text
frames.npy
metadata.json
```

处理含义：

- 把三维数据 `[T, H, W]` 重排为二维矩阵。
- 做 SVD 分解：
  ```text
  M = UΣVᵀ
  ```
- 去掉最大奇异值对应的组织背景。
- 去掉最小奇异值对应的随机噪声。
- 保留中间奇异值对应的微泡信号。
- 支持低阈值 SVD，用来尽量保留低速微泡信号。

输出：

```text
rat_filtered.npy
rat_singular_values.csv
```

`rat_filtered.npy`：

```python
rat_filtered: np.ndarray
shape = [T, H, W]
dtype = float32
```

含义：

- SVD 滤波后的微泡动态信号。
- 是大鼠链路后续定位的输入。

`rat_singular_values.csv`：

```text
rank,singular_value,kept
```

含义：

- `rank`：第几个奇异值。
- `singular_value`：奇异值大小。
- `kept`：该奇异值是否被保留。
- 用于质控和说明 SVD 保留区间。

---

`rat_step02_radial_symmetry_detect.py`

输入：

```text
rat_filtered.npy
metadata.json
```

处理含义：

1. 先用阈值或局部峰值找候选点。
2. 围绕每个候选点裁剪局部 `patch`。
3. 计算 patch 内的梯度 `gx` 和 `gy`。
4. 根据梯度方向估计亮斑中心。
5. 输出亚像素级中心坐标。

输出：

```text
rat_detections.csv
```

字段：

```text
frame_id,x_pixel,y_pixel,x_physical,y_physical,intensity,method
```

含义和人类检测结果相同，但区别是：

- `x_pixel` / `y_pixel` 可以是小数。
- `method` 为 `radial_symmetry`。
- 这是大鼠链路更高精度定位的核心输出。

---

`rat_step03_track_reconstruct.py`

输入：

```text
rat_detections.csv
metadata.json
```

处理含义：

- 和人类 `Step 03` 相同。
- 使用匈牙利算法追踪。
- 根据轨迹速度划分高/低速。
- 累积生成密度图。
- 计算归一化距离、滞留时长、离散度等指标。

输出：

```text
rat_tracks.csv
rat_low_speed_tracks.csv
rat_high_speed_tracks.csv
rat_density_total.png
rat_density_low_speed.png
rat_density_high_speed.png
rat_metrics.csv
rat_summary.txt
```

---

**为什么这样设计**

这样分接口的好处是：

1. 每一步的输入输出固定，不会出现“这一步吃 PNG、下一步吃 ndarray、再下一步吃 CSV”的混乱。
2. 人类和大鼠链路只在前两个算法步骤不同，第三步可以共享核心逻辑。
3. 高/低速划分严格来自轨迹速度，符合 md 说明。
4. 图片只用于展示，不影响计算链路。
5. 后续如果要调参，只需要替换某一步输出，不需要重跑全部流程。
