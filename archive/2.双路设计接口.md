# 当前 Step 接口

本文档描述当前代码之间的接口。历史草案中的 `human_step02_gaussian_detect.py`、`human_step03_track_reconstruct.py`、`rat_step*.py` 已不是当前主流程命名。

## 总原则

Step 之间只传结构化数据：

```text
.npy   图像序列或 mask 数组
.json  元数据、参数、summary
.csv   detections、tracks、metrics
```

PNG 只用于人工检查，除 Step05 mask 绘制默认用 `human_density_slow.png` 做背景外，不把 PNG 当作核心数值输入。

## Step00

文件：

```text
step00_preprocess.py
```

输入：

```text
DICOM
可选 cortex_mask.npy
```

输出：

```text
human_dcm/step00_preprocess/frames.npy
human_dcm/step00_preprocess/metadata.json
human_dcm/step00_preprocess/tic_raw.npy
human_dcm/step00_preprocess/tic_selection.png
human_dcm/step00_preprocess/selected_ranges.json
human_dcm/step00_preprocess/preview_frame_000.png
```

接口函数：

```python
run(
    kind: str,
    dicom: Path | None = None,
    mask_dir: Path | None = None,
    target_frames: int = 200,
    min_frames: int = 200,
    smooth_window: int = 15,
    baseline_seconds: float = 2.0,
    min_enhancement: float = 0.01,
    target_tic: float | None = None,
) -> tuple[Path, Path]
```

返回 `(frames_path, metadata_path)`。

## Human Step01

文件：

```text
human_step01_bandpass.py
```

输入：

```text
frames.npy
metadata.json
profile = rapid | slow
```

输出：

```text
human_filtered.npy
bandpass_stats.json
diagnostic PNG
```

rapid 使用 `ulm_config.py` 里的带通参数；slow 默认 `use_bandpass=false`。

## Human Step02

文件：

```text
human_step02_gaussian_filter.py
```

输入：

```text
human_filtered.npy
metadata.json
```

输出：

```text
human_smoothed.npy
gaussian_stats.json
diagnostic PNG
```

`human_smoothed.npy` 是 Gaussian guide。Step03 用它找局部极大值，再回到 Step01 响应上取强度和阈值。

## Human Step03

文件：

```text
human_step03_track.py
```

输入：

```text
human_filtered.npy
human_smoothed.npy
metadata.json
profile = rapid | slow
```

输出：

```text
human_detections.csv
human_tracks.csv
tracking_summary.txt
diagnostic PNG
```

主要字段：

```text
detections: frame_id,x_pixel,y_pixel,x_physical,y_physical,intensity,method
tracks:     track_id,frame_id,time_s,x_pixel,y_pixel,x_physical,y_physical,velocity
```

Step03 根据 profile 的最大帧间位移、最短轨迹长度和缺失帧规则生成 tracks。slow tracks 只是慢速 profile 轨迹，不等同于肾小球。

## Human Step04

文件：

```text
human_step04_density_metrics.py
```

输入：

```text
rapid/human_tracks.csv
slow/human_tracks.csv
metadata.json
```

输出：

```text
human_rapid_tracks.csv
human_slow_tracks.csv
human_metrics.csv
human_summary.txt
human_density_total.png
human_density_rapid.png
human_density_slow.png
human_density_profile_overlay.png
```

Step04 把 rapid 和 slow 轨迹统一拷贝到一个目录，生成 4 倍超分辨率密度图，并计算轨迹指标。Step05 默认读取 `human_slow_tracks.csv`、`human_rapid_tracks.csv` 和 rapid/slow density。

## Human Step00 统一入口

旧的 label 型目录 runner 已删除。Human 新样本统一通过
`step00_preprocess.py --run-full-pipeline` 调用 Step00-05；Step01-04 的 rapid/slow
中间结果写入当前 `human_dcm/step01_*` 到 `step04_*` 扁平目录。

## Step05 Mask

文件：

```text
human_step05_glomeruli_count.py
```

mask 绘制入口：

```bash
.venv/bin/python human_step05_glomeruli_count.py --mode cortex
.venv/bin/python human_step05_glomeruli_count.py --mode exclude
```

默认输入背景：

```text
human_dcm/step04_density_metrics/human_density_slow.png
```

默认输出：

```text
masks/cortex_mask.npy
masks/cortex_mask_overlay.png
masks/cortex_mask.log.json
masks/exclude_mask.npy
masks/exclude_mask_overlay.png
masks/exclude_mask.log.json
```

全流程样本模式会把 mask 存到：

```text
all_masks/<sample_id>/cortex_mask.npy
all_masks/<sample_id>/exclude_mask.npy
```

## Step05 Count

执行入口：

```bash
.venv/bin/python human_step05_glomeruli_count.py --mode exec
```

默认输入：

```text
human_dcm/step04_density_metrics/human_slow_tracks.csv
human_dcm/step04_density_metrics/human_rapid_tracks.csv
human_dcm/step04_density_metrics/human_density_slow.png
human_dcm/step04_density_metrics/human_density_rapid.png
masks/cortex_mask.npy
masks/exclude_mask.npy
```

默认输出：

```text
human_dcm/step05_glomeruli_count/
```

接口函数：

```python
run_step5_from_cli_defaults(
    label: str | None = None,
    base_dir: str | Path = "human_dcm",
    masks_dir: str | Path = "masks",
    step04_dir: str | Path | None = None,
    output_dir: str | Path | None = None,
    slow_tracks: str | Path | None = None,
    fast_tracks: str | Path | None = None,
    slow_density: str | Path | None = None,
    fast_density: str | Path | None = None,
    cortex_mask: str | Path | None = None,
    exclude_mask: str | Path | None = None,
    step5_config: dict | Step5Config | None = None,
) -> dict
```

计数模式：

```text
healthy_calibration  健康样本默认模式，自动扫 eps，目标接近 450 且优先不低于 400
diagnostic           病肾/未知样本模式，禁用逐样本校准，使用固定 dbscan_eps_mm
```

## Sample Manager

文件：

```text
ulm_sample_manager.py
```

长期样本目录：

```text
all_masks/<sample_id>/<sample_id>.dcm
all_masks/<sample_id>/cortex_mask.npy
all_masks/<sample_id>/exclude_mask.npy
```

`step00_preprocess.py --run-full-pipeline` 会调用 sample manager 解析样本、登记 DICOM、检查缺失 mask，并在必要时触发 Step05 交互式绘制。
