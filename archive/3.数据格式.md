# 当前数据格式

本文件只记录当前代码仍在使用的数据契约。旧的 PNG/MP4 中间输入、loose/strict Step05 输出和 `rat_*` 命名不再作为主流程说明。

## Step00

`frames.npy`

```python
frames: np.ndarray
shape = [T, H, W]
dtype = float32
range = 0.0 ~ 1.0
```

含义：从 DICOM 中裁剪 ROI 后得到的单通道 CEUS score/灰度序列。`frames.npy[0]` 对应 `metadata.json["source_frame_indices"][0]`。

`metadata.json` 常用字段：

```json
{
  "fps": 30.0,
  "frame_time_ms": 33.3333,
  "pixel_size_x": 0.0063787,
  "pixel_size_y": 0.0063787,
  "height": 590,
  "width": 602,
  "frames_saved": 200,
  "source_frame_start": 200,
  "source_frame_end_inclusive": 399,
  "source_frame_indices": [200, 201],
  "frame_selection_method": "tic_absolute_stable_window",
  "tic_mask": {
    "mode": "cortex_mask"
  },
  "color_space_handling": {
    "reason": "rgb_tag_with_jfif_ybr_codestream",
    "decoder_raw": true,
    "convert_from": "YBR_FULL_422",
    "convert_to": "RGB"
  }
}
```

`tic_raw.npy` 是完整源 DICOM 的 TIC，一维 float 数组。`selected_ranges.json` 是 Step00 选择稳定连续窗口的可复查记录。`tic_selection.png` 和 `preview_frame_000.png` 只用于人工检查。

## Step01-02

`human_filtered.npy`

```python
shape = [T, H, W]
dtype = float32
```

rapid profile 是带通后的动态响应；slow profile 默认不做带通，保留 Step00 帧。

`human_smoothed.npy`

```python
shape = [T, H, W]
dtype = float32
```

这是 Gaussian guide，用于 Step03 局部极大值搜索。

## Step03

`human_detections.csv`

```text
frame_id,x_pixel,y_pixel,x_physical,y_physical,intensity,method
```

一行是一个微泡候选点。

`human_tracks.csv`

```text
track_id,frame_id,time_s,x_pixel,y_pixel,x_physical,y_physical,velocity
```

一行是一个轨迹点。同一 `track_id` 的多行组成一条微泡轨迹。

## Step04

`human_rapid_tracks.csv` 和 `human_slow_tracks.csv` 是 Step03 tracks 按 profile 输出后的统一输入，供 Step04/Step05 使用。

`human_metrics.csv` 常用含义：

```text
track_id
point_count
duration_s
path_length_mm
end_to_end_distance_mm
normalized_distance
mean_speed_mm_s
center_x_pixel
center_y_pixel
```

`human_density_total.png`、`human_density_rapid.png`、`human_density_slow.png` 和 overlay 图是密度可视化，不作为数值契约的唯一来源。

## Step05

`summary.json` 是 Step05 参数、输入路径、计数和 warning 的总索引。

`config.json` 是本次运行的 Step05 参数快照，用于复现。

`track_metrics.csv` 是每条 slow track 的派生指标。`filtered_points.csv` 是最终参与肾小球候选分布的轨迹点。`per_block_counts.csv` 是分块计数诊断。`final_glomeruli.csv` 是最终 DBSCAN 聚类后的候选肾小球中心。

中间数组：

```text
nd_map_raw_iso.npy       原始 normalized-distance map
nd_map_iso.npy           平滑后的 normalized-distance map
seed_mask_iso.npy        高 ND 种子区
glomerular_mask_iso.npy  按肾小球半径扩张后的候选区
fast_vessel_mask_iso.npy 快速血管排除区
cortex_mask_iso.npy      cortex mask 转到 iso grid 后的结果
exclude_mask_iso.npy     exclude mask 转到 iso grid 后的结果
glomerular_track_density.npy 筛选后轨迹点密度
```

可视化：

```text
nd_map_iso.png
slow_density_overlay_cortex.png
glomerular_mask_overlay.png
fast_exclusion_overlay.png
track_filter_diagnostics.png
final_glomeruli_centers.png
glomerular_track_distribution.png
glomerular_track_distribution_on_slow_density.png
```

当前 Step05 只有单一候选集。旧的 `final_glomeruli_centers_loose.png`、`final_glomeruli_centers_strict.png`、`loose_count`、`strict_count` 不再是当前输出。
