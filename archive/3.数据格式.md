**统一数据契约**
1. 图像序列统一为 `.npy` / `np.ndarray`
   ```python
   frames: np.ndarray
   shape = [T, H, W]
   dtype = float32
   range = 0.0 ~ 1.0
   ```
   任何 DICOM、RGB、uint8、ROI 裁剪，都只在入口阶段转换一次。后续模块不再接收 PNG/JPG/MP4。

2. 元数据统一为 `metadata.json`
   ```json
   {
     "fps": 30.0,
     "frame_time_ms": 33.3333,
     "pixel_size_x": 0.0063787,
     "pixel_size_y": 0.0063787,
     "height": 512,
     "width": 512
   }
   ```

3. 微泡检测结果统一为 `detections.csv`
   ```text
   frame_id,x_pixel,y_pixel,x_physical,y_physical,intensity,method
   ```

4. 轨迹结果统一为 `tracks.csv`
   ```text
   track_id,frame_id,time_s,x_pixel,y_pixel,x_physical,y_physical,velocity
   ```

5. 高/低速划分统一发生在追踪之后
   ```text
   tracks.csv -> low_speed_tracks.csv + high_speed_tracks.csv
   ```
   不再把滤波输出直接命名成 `low_speed_frames.npy` / `high_speed_frames.npy`，避免概念错误。
