## 1. 文档定位

本文面向超声定位显微镜（Ultrasound Localization Microscopy, ULM）或超声微泡成像后处理展示，重点整理从原始帧序列到微泡检测、定位、追踪、速度划分与血流密度图生成的技术流程。

核心思路可以概括为：

```text
多帧超声/微泡图像
    → 时域滤波 / SVD 滤波
    → 单帧平滑与候选点检测
    → 亚像素定位

    → 速度计算与高/低速分组
    → 血流密度图与定量参数
```

## 2. Step 01：时域带通滤波器（人类实验适用）

### 2.1 基本概念

时域带通滤波器针对每个空间位置 \((x, y)\) 上的时间序列 \(I(x,y,t)\) 进行滤波。其目标是去掉慢变化背景和高频随机噪声，保留微泡通过时引起的动态变化。

在 ULM 或超声微泡成像中，组织背景、呼吸运动、探头微小晃动等通常表现为低频或慢变化成分；随机电子噪声、压缩噪声等可能表现为高频扰动。带通滤波用于保留微泡运动所对应的中间频段。

### 2.2 适用场景

- 可作为人体样本或实验样本中的基础滤波方法。
- 已知帧率 `fps` 时，可根据微泡运动频段设置 `lowcut` 与 `highcut`。
- 常与 SVD 滤波串联使用，作为二次滤波或预处理步骤。

### 2.3 Python 实现示例

```python
from scipy.signal import butter, filtfilt


def temporal_bandpass(frames, fs, lowcut, highcut):
    b, a = butter(3, [lowcut / (fs / 2), highcut / (fs / 2)], btype="band")
    return filtfilt(b, a, frames, axis=0)
```

### 2.4 参数解释

| 参数 | 含义 | 设置建议 |
|---|---|---|
| `frames` | 输入帧序列，通常形状为 `[T, H, W]` | 时间维度应放在 `axis=0` |
| `fs` | 采样频率/帧率 | 从 DICOM metadata 或设备记录中获取 |
| `lowcut` | 低截止频率 | 用于去除组织、呼吸等慢变化背景 |
| `highcut` | 高截止频率 | 用于去除随机高频噪声 |
| `axis=0` | 沿时间轴滤波 | 对每个像素点的时间曲线做滤波 |

展示时建议配一张“单像素时间曲线”的滤波前后对比图，比单纯展示代码更容易说明效果。

## 3. Step 01：时空奇异值分解滤波器（SVD Filter）（小鼠实验适用）

### 3.1 核心变换

SVD 滤波的基本流程是将三维时空数据重排为二维矩阵，然后进行奇异值分解：

```text
frames [T, H, W]
    → M [H×W, T]
    → M = UΣVᵀ
```

其中，空间维度 \(H \times W\) 被展平成矩阵行，时间维度 \(T\) 作为矩阵列。SVD 将数据分解为不同能量和相关性的时空成分。

### 3.2 奇异值对应的信号类型

| 奇异值范围 | 常见含义 | 处理策略 |
|---|---|---|
| 大奇异值 | 组织杂波、背景、强相关慢变化成分 | 通常剔除 |
| 中间奇异值 | 微泡运动信号 | 重点保留 |
| 小奇异值 | 随机噪声 | 通常剔除 |

### 3.3 Python 实现思路

```python
from scipy.linalg import svd

# 大数据可考虑 randomized_svd
U, S, Vt = svd(M, full_matrices=False)
S_keep = mask(S, low_rank_cut, high_rank_cut)
M_filtered = (U * S_keep) @ Vt
```

上述代码只是核心逻辑。实际工程中还需要完成：

1. 将 `[T, H, W]` 重排为 `[H*W, T]`。
2. 设置 `low_rank_cut` 与 `high_rank_cut`。
3. 构造只保留中间奇异值的 mask。
4. 重建滤波后的矩阵。
5. 再把 `[H*W, T]` 还原回 `[T, H, W]`。

## 4. 低阈值 SVD 与高/低速微泡数据

### 4.1 低阈值 SVD 的含义

低阈值 SVD 指只去掉少量最大奇异值，尽量保留低速微泡信号。低速微泡移动较慢，时空相关性相对较高，因此容易被普通 SVD 误判为组织背景并被滤除。

普通 SVD 的组织抑制更强，但可能误删低速微泡：

```python
filtered, S = svd_filter(frames, low_rank_cut=10, high_rank_cut=80)
```

低阈值 SVD 更偏向保留低速微泡：

```python
filtered_low, S = svd_filter(frames, low_rank_cut=2, high_rank_cut=80)
```

### 4.2 高/低速微泡的划分

高/低速微泡数据通常来自轨迹速度，而不是单帧图像强度。

速度计算公式为：

```text
速度 = 位移 × 像素尺寸 × 帧率
```

不同速度区间可以对应不同血流结构：

| 类别 | 常见位置或意义 |
|---|---|
| 高速微泡 | 主干血管、快速灌注区域 |
| 低速微泡 | 微小血管、毛细血管、局部滞留区域 |

## 5. Step 02：二维高斯滤波器（人类样本）

### 5.1 作用机制

二维高斯滤波器作用于单帧图像，用于让微泡亮斑更加稳定和连续：

```text
单帧图像 → 高斯平滑 → 局部亮斑更连续 → 更容易找峰值
```

主要作用包括：

- 抑制孤立噪声点，降低误检率。
- 保持微泡近似 blob 的结构。
- 为 `peak_local_max` 或阈值检测提供更稳定的输入。
- 提高后续候选点检测的鲁棒性。

需要注意，`sigma` 不宜过大，否则相邻微泡可能被平滑融合，导致定位和计数错误。

### 5.2 Python 实现示例

```python
from scipy.ndimage import gaussian_filter

# 或使用 OpenCV: cv2.GaussianBlur
smooth = gaussian_filter(frame, sigma=1.0)
```

### 5.3 参数建议

| 参数 | 建议范围 | 说明 |
|---|---:|---|
| `sigma` | 0.8–2.0 | 可作为初始调参范围 |
| 微泡小且密集 | 较小 sigma | 避免相邻微泡融合 |
| 噪声较强 | 适当增大 sigma | 提升平滑效果，但需防止过平滑 |

## 6. Step 02：径向对称法（小鼠样本）

### 6.1 基本思想

径向对称法用于从微泡亮斑中估计亚像素级中心位置。基本假设是：微泡亮斑周围的灰度梯度大致指向中心，因此可以将多条梯度方向线求交，得到更精确的中心坐标。

### 6.2 与常规极值定位的区别

| 方法 | 原理 | 优点 | 局限 |
|---|---|---|---|
| 常规极值定位 | 取最亮像素点 | 简单、速度快 | 只有像素级精度，易受噪声影响 |
| 径向对称定位 | 利用梯度方向估计中心 | 可达到亚像素级，更适合超分辨血管重建 | 通常需要自定义实现 |

### 6.3 实现步骤

径向对称法通常没有一个完全标准的现成函数，需要根据数据特点自定义实现。典型流程如下：

1. 根据候选点裁剪局部 `patch`。
2. 计算局部梯度 `gx` 与 `gy`。
3. 根据梯度方向构造加权最小二乘问题。
4. 求解中心点坐标。
5. 将局部坐标转换为全局图像坐标。

## 7. Step 03：匈牙利算法与微泡追踪

### 7.1 问题定义

在第 `t` 帧中有 `M` 个微泡，第 `t+1` 帧中有 `N` 个微泡。追踪任务需要判断相邻两帧中哪些点属于同一个微泡轨迹。

可以构造代价矩阵：

```text
cost[i, j] = 第 t 帧第 i 个点与第 t+1 帧第 j 个点之间的距离
```

匈牙利算法用于寻找总代价最小的匹配方案。

### 7.2 Python 实现示例

```python
from scipy.optimize import linear_sum_assignment
from scipy.spatial.distance import cdist

cost = cdist(points_t, points_t1)
row, col = linear_sum_assignment(cost)
```

### 7.3 追踪约束

单纯的匈牙利算法只解决“当前两帧最优匹配”，完整微泡追踪还需要轨迹管理逻辑。常见约束包括：

- 最大允许位移 `max_distance`。
- 最小轨迹长度 `min_track_length`。
- 速度连续性约束。
- 方向连续性约束。
- 短时丢失后继续连接，或直接终止轨迹。

因此，工程实现中通常需要自定义 `track_bubbles` 之类的函数，将局部匹配结果维护成完整轨迹。

## 8. Step 04：合成高/低速血流密度图与参数计算

### 8.1 从轨迹到血流密度图

处理流程为：

```text
轨迹 → 速度 → 分组 → 累计成图
```

根据速度阈值，可以将微泡轨迹划分为高速轨迹和低速轨迹。随后将轨迹点累计到图像网格中，得到血流密度图。

| 轨迹类型 | 主要对应区域 |
|---|---|
| 高速轨迹 | 主干血管、快速灌注区域 |
| 低速轨迹 | 毛细血管、局部滞留区域 |

展示结果时，建议使用不同颜色区分高速与低速轨迹，并在图旁边给出参数定义，形成“结果图 + 指标解释”的组合。

### 8.2 定量参数

| 参数 | 定义 | 反映意义 |
|---|---|---|
| 归一化距离 | 轨迹总长度 / 首尾直线距离 | 反映轨迹弯曲程度 |
| 滞留时长 | 微泡在指定圆形区域内被追踪到的时间 | 反映局部滞留或灌注特点 |
| 离散度 | 统计方向偏差 ±20° 内的同向运动次数 | 反映运动方向一致性 |

## 10. 建议的软件处理管线

结合上述技术点，可以将 ULM 后处理拆成如下管线：

### 10.1 数据读取

输入数据通常是多帧超声视频、DICOM cine-loop、导出的图像序列，或已经完成初步成像的 ULM 结果。

需要首先确认：

- 帧数 `T`。
- 图像尺寸 `H × W`。
- 帧率 `fps`。
- 像素尺寸，即每个像素对应的实际物理长度。
- 图像是灰度、RGB 还是伪彩色。
- 是否存在压缩、设备 UI 叠加、标尺文字等干扰。

### 10.2 预处理

预处理阶段建议包括：

1. 灰度化或通道选择。
2. 归一化或 window 调整。
3. 时域带通滤波。
4. SVD 滤波。
5. 单帧高斯平滑。

### 10.3 微泡候选点检测

可以使用局部峰值检测或阈值检测。常用方向是：

```python
from skimage.feature import peak_local_max

points = peak_local_max(
    smooth_frame,
    min_distance=3,
    threshold_abs=threshold,
)
```

关键参数包括：

- `threshold_abs`：候选点强度阈值。
- `min_distance`：候选峰之间的最小距离。
- ROI mask：限制检测区域，避免背景误检。

### 10.4 亚像素定位

候选点检测完成后，可在每个候选点附近裁剪 patch，并使用径向对称法或二维高斯拟合估计中心位置。若展示场景对精度要求不高，也可以先使用像素级峰值位置作为初版结果。

### 10.5 轨迹追踪

相邻帧之间通过距离矩阵和匈牙利算法完成初步匹配，再根据最大位移、速度连续性和轨迹长度筛选轨迹。

### 10.6 结果合成

将轨迹点按照速度阈值分为高速和低速，分别累计到图像网格中，得到：

- 总血流密度图。
- 高速血流密度图。
- 低速血流密度图。
- 轨迹叠加图。
- 速度分布统计图。
