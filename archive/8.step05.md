## 非画 mask 的计数流程

上面两段命令只负责**画 mask**，也就是生成：

```text

masks/exclude_mask_overlay.png
masks/exclude_mask.log.json
```

真正的 Step05 正常运行，是读取 Step04 的 rapid/slow 轨迹和密度图，再结合已经画好的 cortex/exclude mask，执行肾小球候选筛选、聚类计数和诊断图输出。

## Step05 正常运行的功能注释

### 1. `slow_tracks`

```python
slow_tracks=step04_dir / "human_slow_tracks.csv"
```

这是 Step05 的主输入。每一行是一个慢速轨迹点，至少需要这些字段：

```text
track_id
frame_id 或 frame
x_pixel 或 x_px
y_pixel 或 y_px
```

Step05 会把这些点按 `track_id` 分组，计算每条轨迹的：

```text
轨迹点数
持续时间
路径长度
直线距离
normalized_distance
中心点坐标
cortex/exclude/border 内部比例
```

慢速轨迹越像肾小球局部微循环，越可能被保留下来。

### 2. `fast_tracks`

```python
fast_tracks=step04_dir / "human_rapid_tracks.csv"
```

快速轨迹主要用于辅助识别大血管或快速流动区域。当前命令同时提供了 `fast_density`，因此主血管排除优先基于 `fast_density` 做；如果没有 `fast_density`，代码可以从 `fast_tracks` 临时投影出快速密度图。

### 3. `slow_density`

```python
slow_density=_load_array(step04_dir / "human_density_slow.png")
```

用途：

```text
1. 辅助估计原始图像 shape。
2. 作为 Step05 诊断图背景。
3. 生成 glomerular_track_distribution_on_slow_density.png。
```

注意：Step04 的 density PNG 通常是超分辨率显示图，例如 4 倍尺寸。Step05 会自动识别这种放大比例，并还原到轨迹的原始像素坐标系。

### 4. `fast_density`

```python
fast_density=_load_array(step04_dir / "human_density_rapid.png")
```

用途：

```text
1. 在 cortex 范围内取 fast density 的高百分位区域。
2. 生成 fast_vessel_mask_iso。
3. 排除主血管和快速流动区域附近的候选。
```

相关默认参数在 `Step5Config` 中：

```python
fast_vessel_percentile = 99.5
fast_vessel_dilate_mm = 0.0
```

含义：

```text
只取 fast density 前 0.5% 高亮区域作为主血管候选，并且默认不再向外扩张。
```

这组默认值比旧设置更弱。旧设置是 `fast_vessel_percentile=98.0`、`fast_vessel_dilate_mm=0.06`，会把主血管区域扩得更大，容易把肾小球附近的慢速轨迹一起排掉。

### 7. `output_dir`

```python
output_dir=step05_dir
```

Step05 输出会集中写到：

```text
human_dcm/step05_glomeruli_count/<label>/
```

关键输出包括：

```text

config.json
track_metrics.csv
filtered_points.csv
per_block_counts.csv
final_glomeruli.csv
nd_map_raw_iso.npy
nd_map_iso.npy
seed_mask_iso.npy
glomerular_mask_iso.npy
fast_vessel_mask_iso.npy
cortex_mask_iso.npy
exclude_mask_iso.npy
nd_map_iso.png
slow_density_overlay_cortex.png
glomerular_mask_overlay.png
fast_exclusion_overlay.png
track_filter_diagnostics.png
final_glomeruli_centers.png
glomerular_track_density.npy
glomerular_track_distribution.png

```

## 解释说明

这些都是 Step05 的输出，分成几类看最清楚。

**核心结果**

`summary.json`  
本次 Step05 的总摘要。里面会有轨迹数量、过滤后数量、最终肾小球计数、参数、warning 等。优先看这个判断结果是否正常。

`config.json`  
本次运行实际使用的 Step05 参数快照，例如 `dbscan_eps_mm`、`glomerulus_radius_mm`、`fast_vessel_percentile` 等。用于复现结果。

`final_glomeruli.csv`  
最终肾小球候选中心表。每一行通常代表一个聚类后的肾小球候选，包括中心坐标、包含轨迹数、block 数、median normalized distance 等。这是 Step05 最核心的计数结果。

`filtered_points.csv`  
被判定为“肾小球相关轨迹”的原始轨迹点。它不是中心点，而是筛选后保留下来的轨迹点集合，用来重建分布图和追溯哪些轨迹贡献了候选。

`track_metrics.csv`  
每条 slow track 的指标表。包括轨迹长度、持续时间、normalized distance、是否通过 cortex/exclude/border/fast vessel 等过滤条件。调参和排查误检主要看它。

`per_block_counts.csv`  
按 `block_id` 分块统计的肾小球候选数量。当前如果没有多 block，通常只有 `block_id=0`。

**中间 NPY mask / map**

`nd_map_raw_iso.npy`  
原始 normalized-distance map，已经转换到 isotropic 物理网格。数值高的区域表示慢速轨迹更曲折/驻留，更像肾小球候选。

`nd_map_iso.npy`  
平滑后的 normalized-distance map。后续 seed mask 基于这个更稳定的图生成。

`seed_mask_iso.npy`  
从 high-ND 区域提取出的种子 mask。它是生成肾小球候选区域的起点。

`glomerular_mask_iso.npy`  
由 seed mask 按肾小球半径扩张后得到的肾小球候选区域 mask。轨迹点落在这个 mask 里，才更可能被保留为肾小球相关轨迹。

`fast_vessel_mask_iso.npy`  
由 rapid density 高亮区域生成的主血管排除 mask。用于避免把大血管附近的慢速轨迹误计为肾小球。

`cortex_mask_iso.npy`  
人工画的 cortex mask 转换到 isotropic grid 后的版本。Step05 内部统一在这个物理网格上计算。

`exclude_mask_iso.npy`  
人工画的 exclude mask 转换到 isotropic grid 后的版本。用于排除伪影、非肾组织、明显异常区域。

**可视化 PNG**

`nd_map_iso.png`  
平滑 normalized-distance map 的可视化。看 high-ND 区域是否集中在合理的皮质区域。

`slow_density_overlay_cortex.png`  
慢速密度图叠加 cortex mask。用来检查 cortex ROI 是否覆盖正确。

`glomerular_mask_overlay.png`  
慢速背景上叠加肾小球候选 mask。看候选区域是否合理。

`fast_exclusion_overlay.png`  
快速密度图上叠加 fast vessel 排除区域。看大血管排除是否过多或过少。

`track_filter_diagnostics.png`  
轨迹过滤诊断图。显示所有慢速轨迹中心和最终保留候选中心，用于判断过滤条件是否太严或太松。

`final_glomeruli_centers.png`  
最终肾小球候选中心图。最直观地看最终计数位置是否合理。

**肾小球轨迹分布**

`glomerular_track_density.npy`  
筛选后的肾小球相关轨迹点重建出的密度矩阵，NPY 版本，便于后续分析。

`glomerular_track_distribution.png`  
上面 density 的可视化图。显示被认为与肾小球相关的轨迹点空间分布。

`glomerular_track_distribution_on_slow_density.png`  
肾小球相关轨迹分布叠加在 slow density 背景上。通常最适合人工检查：能看到候选轨迹是否落在慢速微循环聚集区域。

## Step05 内部流程概览

正常运行 `run_step5_glomeruli_count(...)` 后，大致步骤是：

1. 读取并标准化 `slow_tracks`。
2. 根据轨迹、density、mask 推断原始图像 shape。
3. 把 cortex/exclude/border/fast-vessel mask 转换到 isotropic grid。
4. 计算每条慢速轨迹的 normalized distance、持续时间、路径长度、中心点等指标。
5. 用 cortex/exclude/border 条件筛选可用慢速轨迹。
6. 用慢速轨迹构建 normalized-distance map。
7. 从 high-ND 区域生成 seed mask。
8. 按肾小球半径扩张 seed，生成 glomerular mask。
9. 反向筛选落在 glomerular mask 内的轨迹点。
10. 用 DBSCAN 对候选轨迹中心聚类，得到最终肾小球候选中心和计数。
11. 写出 CSV、NPY、PNG 和 `summary.json`。

## 调参方向：把计数推到 400+

当前 `stable_200_400` 旧结果：

```text
roi_keep = 696
fast vessel 后保留 = 548
glomeruli_count = 367
```

说明 fast-vessel 排除在 ROI 后又排掉了 `148` 条轨迹，是计数偏低的重要原因。

本次将默认参数改为：

```python
fast_vessel_percentile = 99.5
fast_vessel_dilate_mm = 0.0
dbscan_eps_mm = 0.17
```

临时测试输出到：

```text
human_dcm/step05_glomeruli_count/stable_200_400_paramtest/
```

测试结果：

```text
roi_keep = 696
fast vessel 后保留 = 680
glomeruli_count = 421
```

这说明最有效的调参方向是：

1. 调高 `fast_vessel_percentile`：例如 `98.0 -> 99.5`，只把最亮的 fast density 当主血管。
2. 调低 `fast_vessel_dilate_mm`：例如 `0.06 -> 0.0`，避免主血管 mask 扩张后误杀邻近候选。
3. 略微调低 `dbscan_eps_mm`：例如 `0.19 -> 0.17`，减少 DBSCAN 把相邻候选合并成一个中心。

不优先建议用 `nd_percentile` 或 `nd_track_percentile` 来拉计数，因为当前最终 `final_glomeruli.csv` 来自 `candidate_keep` 轨迹中心的 DBSCAN 聚类；ND map 更多影响中间 mask 和分布图，而不是当前最终候选中心数量的主旋钮。
