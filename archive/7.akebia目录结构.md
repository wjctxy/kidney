```
akebia/
├── .git/                           ← Git 仓库（Akebia 本身是一个独立 git 项目）
├── README.md                       ← 项目说明
├── Images/                         ← 宣传用图片
│   ├── logo_akebia.png
│   └── Rat14Kidney_Density.png
├── Results/                        ← 示例输出结果（TIFF 格式）
│   ├── HumanDensity.tif            ← 人类密度图
│   ├── HumanDirectivity.tif        ← 人类方向图
│   ├── HumanVelocity.tif           ← 人类速度图
│   ├── Rat14Kidney_Density.tif     ← 大鼠密度图
│   ├── Rat14Kidney_Directivity.tif ← 大鼠方向图
│   └── Rat14Kidney_Velocity.tif    ← 大鼠速度图
├── Software AKEBIA/                ← 独立 GUI 软件
│   ├── Akebia_v1.0_Installer.exe   ← Windows 安装程序
│   ├── Akebia_User_Guide.pdf       ← 用户手册
│   └── README.md
└── Example script/                 ← 算法示例脚本（核心）
    ├── README.md
    ├── examples/                   ← 用户入口脚本
    │   ├── Akebia_example_script.m ← 主入口
    │   ├── akebia_human.m          ← 人类临床数据管线
    │   └── akebia_rat.m            ← 大鼠/小鼠数据管线
    ├── src/                        ← Akebia 自己的核心函数
    │   ├── app/                    ← 应用层
    │   │   ├── CreateTrackingProfile.m ← 构建追踪参数配置
    │   │   └── LoadData.m              ← 加载 .mat 数据
    │   ├── compute/                ← 计算层
    │   │   ├── BlockInterp2Track.m     ← human：滤波→定位→追踪
    │   │   ├── BlockNoInterp2Track.m   ← rat：SVD→径向对称→追踪
    │   │   ├── ULM_localization2D_interp.m ← 插值数据微泡定位
    │   │   └── Track2MatOut_multi.m    ← 轨迹→密度/方向/速度矩阵
    │   └── plot/                   ← 可视化层
    │       ├── PlotDensity.m       ← 密度图绘制
    │       ├── PlotDirectivity.m   ← 方向图绘制
    │       ├── PlotVelocity.m      ← 速度图绘制
    │       └── PlotScaleBar.m      ← 比例尺
    └── lib/                        ← 第三方开源库
        ├── SimpleTracker/          ← 匈牙利追踪（SimpleTracker）
        │   ├── simpletracker.m     ← 主追踪器
        │   ├── hungarianlinker.m   ← 匈牙利匹配
        │   ├── munkres.m           ← Munkres 算法实现
        │   └── nearestneighborlinker.m ← 最近邻匹配
        └── ULM-PALA/               ← PALA 工具箱（微泡定位/追踪）
            ├── SVDfilter.m         ← SVD 时空滤波
            ├── ULM_localization2D.m       ← 2D 微泡定位
            ├── ULM_tracking2D.m           ← 2D 轨迹追踪
            ├── ULM_Track2MatOut.m         ← 轨迹→矩阵输出
            └── localizeRadialSymmetry.m   ← 径向对称亚像素定位
```

### 层级关系

```
examples/ (入口)       →  调用 src/app/ (加载+配置)
                              ↓
                         src/compute/ (滤波→定位→追踪)
                              ↓
                         lib/ (SimpleTracker / ULM-PALA)
                              ↓
                         src/plot/ (密度/速度/方向图)
```

### 与我们项目对应

| Akebia                                  | 我们项目                               |
| --------------------------------------- | -------------------------------------- |
| `examples/akebia_human.m`               | `human_step01-04` 管线                 |
| `examples/akebia_rat.m`                 | `mouse_step01-03` 管线                 |
| `src/compute/BlockInterp2Track.m`       | `step01+step02+step03`（合并）         |
| `src/compute/Track2MatOut_multi.m`      | `step04`（密度+指标）                  |
| `lib/SimpleTracker/`                    | ulm_tracking.py（匈牙利追踪）          |
| `lib/ULM-PALA/SVDfilter.m`              | mouse_step01_svd_filter.py             |
| `lib/ULM-PALA/localizeRadialSymmetry.m` | mouse_step02_radial_symmetry_detect.py |
| `Software AKEBIA/`                      | 无对应（独立 GUI 软件）                |
