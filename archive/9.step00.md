# Human Run Profiles 自动 DICOM 截帧改动记录

日期：2026-06-08

## 背景

原先 `human_run_profiles.py` 默认读取已经存在的：

```text
human_dcm/step00_preprocess/stable_200_400/frames.npy
human_dcm/step00_preprocess/stable_200_400/metadata.json
```

这意味着 profile pipeline 本身不负责从 DICOM 生成 Step00 输入，也没有真正实现“从源视频某一帧开始截取固定帧数”。`stable_200_400` 只是目录标签，不是由当前代码自动生成的帧范围。

## 本次修改

### 1. `human_run_profiles.py` 增加自动 Step00 预处理

当没有显式传入 `--frames` 和 `--metadata` 时，`human_run_profiles.py` 会自动：

1. 扫描项目根目录中的 `.dcm` / `.dicom` 文件。
2. 要求根目录存在且只存在一个 DICOM 文件。
3. 从 `--source-frame-start` 指定的源帧开始读取。
4. 默认保存 `--frame-count 200` 帧。
5. 生成：

```text
human_dcm/step00_preprocess/<label>/frames.npy
human_dcm/step00_preprocess/<label>/metadata.json
human_dcm/step00_preprocess/<label>/preview_frame_000.png
```

随后继续执行 rapid / slow 两套 Human profile。

### 2. 新增 CLI 参数

```bash
python3 human_run_profiles.py --source-frame-start 200
```

默认含义：

```text
source_frame_start = 200
frame_count = 200
实际源帧范围 = 200 到 399
```

如果需要复现旧目录名 `stable_200_400`，且包含源帧 200 到 400 共 201 帧：

```bash
python3 human_run_profiles.py \
  --label stable_200_400 \
  --source-frame-start 200 \
  --frame-count 201
```

### 3. 自动生成 label

未指定 `--label` 时，label 根据 DICOM 文件名和源帧窗口生成：

```text
<dicom_stem>_<source_frame_start>_<source_frame_end_inclusive>
```

例如：

```text
11.0_200_399
```

如果 `--frame-count 0`，表示从起始帧保存到 DICOM 末尾，label 会形如：

```text
11.0_200_end
```

### 4. `ulm_io.dicom_to_frames` 支持源帧起点

`ulm_io.dicom_to_frames` 新增参数：

```python
source_frame_start: int = 0
```

读取逻辑从：

```python
read_pixel_array(dicom_path, index=frame_id)
```

改为：

```python
source_frame_id = source_frame_start + frame_id
read_pixel_array(dicom_path, index=source_frame_id)
```

这样保存的 `frames.npy` 本地 index 仍然从 0 开始，但 metadata 会记录其对应源 DICOM 帧范围。

## Metadata 新增字段

`metadata.json` 现在会额外保存：

```json
{
  "source_frame_start": 200,
  "source_frame_end_exclusive": 400,
  "source_frame_end_inclusive": 399,
  "frames_saved": 200
}
```

注意：

- `source_frame_end_exclusive` 遵循 Python 切片语义，不包含该帧。
- `source_frame_end_inclusive` 是实际保存的最后一帧源 DICOM 编号。
- `frames.npy[0]` 对应 `source_frame_start`。

## 兼容性

自动模式不支持通过命令行指定 DICOM 文件名。默认约定是项目根目录只放一个 `.dcm` / `.dicom` 文件；如果放了多个，程序会报错，避免静默选错样本。

保留旧入口：

```bash
python3 human_run_profiles.py --frames path/to/frames.npy --metadata path/to/metadata.json
```

但 `--frames` 和 `--metadata` 必须同时提供。只提供其中一个会报错，避免输入不一致。

### 8. 自动 label 规则

文件：

```text
human_run_profiles.py
```

位置：

```python
def _default_label(dicom_path: Path, source_frame_start: int, frame_count: int | None) -> str:
    safe_stem = re.sub(r"[^A-Za-z0-9_.-]+", "_", dicom_path.stem).strip("._-") or "dicom"
    if frame_count is not None and frame_count > 0:
        source_frame_end = source_frame_start + frame_count - 1
        return f"{safe_stem}_{source_frame_start}_{source_frame_end}"
    return f"{safe_stem}_{source_frame_start}_end"
```

例子：

```text
根目录 DICOM: 5.0.dcm
source_frame_start: 0
frame_count: 200
自动 label: 5.0_0_199
```

## 常用运行指令

### 默认跑全流程到 Step04

要求：项目根目录只放一个 `.dcm` 或 `.dicom`。

```bash
.venv/bin/python human_run_profiles.py
```

默认行为：

```text
从源 DICOM 第 0 帧开始截 200 帧。
输出 label 自动生成，例如 5.0_0_199。
执行 Step00、Rapid/Slow Step01、Step02、Step03、Step04。
不执行 Step05。
```

### 从源 DICOM 第 200 帧开始截 200 帧

```bash
.venv/bin/python human_run_profiles.py --source-frame-start 200
```

源帧范围：

```text
200-399
```

### 从源 DICOM 第 200 帧开始截到第 400 帧，包括 400

```bash
.venv/bin/python human_run_profiles.py \
  --label stable_200_400 \
  --source-frame-start 200 \
  --frame-count 201
```

源帧范围：

```text
200-400
```

### 从某一帧开始保存到 DICOM 末尾

```bash
.venv/bin/python human_run_profiles.py \
  --source-frame-start 200 \
  --frame-count 0
```

### 使用已经生成好的 frames.npy 和 metadata.json

```bash
.venv/bin/python human_run_profiles.py \
  --frames human_dcm/step00_preprocess/5.0_0_199/frames.npy \
  --metadata human_dcm/step00_preprocess/5.0_0_199/metadata.json
```

注意：`--frames` 和 `--metadata` 必须同时提供。

### 指定 Step03 预览图本地帧号

```bash
.venv/bin/python human_run_profiles.py \
  --source-frame-start 200 \
  --preview-frame 100
```

如果 `source_frame_start=200`，这里的 `preview_frame=100` 对应源 DICOM 第 300 帧。
