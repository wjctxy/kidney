# 项目总览

日期：2026-06-15

本项目用于肾脏 CEUS/ULM 后处理。当前主线是 human pipeline：

```text
DICOM
-> Step00 TIC 选择连续稳定造影窗口
-> Step01 rapid/slow 时域处理
-> Step02 Gaussian guide
-> Step03 微泡检测和追踪
-> Step04 密度图和轨迹指标
-> Step05 cortex/exclude mask
-> Step05 肾小球候选计数
```

## 当前推荐入口

新样本优先使用 Step00 的全流程入口：

```bash
.venv/bin/python step00_preprocess.py --kind human --run-full-pipeline --sample 21.0
```

也可以直接登记 DICOM：

```bash
.venv/bin/python step00_preprocess.py --kind human --run-full-pipeline --dicom 21.0.dcm
```

```text
archive/healthy_step05_runs/<sample_id>_summary.json
```

## 统一数据约定

核心 Step 之间传结构化数据：

```text
frames.npy        float32 [T,H,W]
metadata.json     fps、pixel size、ROI、源帧映射、TIC 选窗记录
*_detections.csv  每行一个微泡候选点
*_tracks.csv      每行一个轨迹点
*_metrics.csv     轨迹或候选目标指标
*.png             人工检查图，不作为唯一数值契约
```

详细字段见 `archive/3.数据格式.md`。

## Step00：DICOM 预处理和 TIC 选帧

入口：

```bash
.venv/bin/python step00_preprocess.py --kind human
.venv/bin/python step00_preprocess.py --kind human --target-frames 400
```

默认参数在 `step00_preprocess.py`：

```text
DEFAULT_TARGET_FRAMES = 401
DEFAULT_MIN_FRAMES = 1
DEFAULT_SMOOTH_WINDOW = 15
DEFAULT_BASELINE_SECONDS = 2.0
DEFAULT_MIN_ENHANCEMENT = 0.01
```

主要逻辑：

```text
读取完整 DICOM
处理 RGB/YBR_FULL_422 颜色空间冲突
裁剪 ROI
计算完整源 DICOM TIC
枚举固定长度连续窗口
普通模式按 --start-frame/--frame-count 手动选窗；full pipeline 有 cortex mask 时按 cortex TIC 峰值居中选窗
保存 frames.npy 和 metadata.json
```

TIC 使用规则：

```text
有 cortex_mask.npy：TIC = cortex 内平均 CEUS score
无 cortex_mask.npy：不计算 TIC，使用手动帧窗口
```

输出：

```text
human_dcm/step00_preprocess/frames.npy
human_dcm/step00_preprocess/metadata.json
human_dcm/step00_preprocess/tic_raw.npy
human_dcm/step00_preprocess/tic_selection.png
human_dcm/step00_preprocess/selected_ranges.json
human_dcm/step00_preprocess/preview_frame_000.png
```

Step00 不再默认取前 600 帧，也不按总帧数比例取窗口。详细说明见 `archive/9.step00.md`。

## Step01-04：Human rapid/slow 轨迹

全流程入口会自动跑 rapid 和 slow 两套 profile。旧的 label 型入口已删除；
新样本统一使用 `step00_preprocess.py --run-full-pipeline`。

profile 参数在 `ulm_config.py`：

```text
rapid:
  use_bandpass = true
  bandpass = [1.0, 5.5] Hz
  max_frame_displacement_px = 15
  min_track_length = 5

slow:
  use_bandpass = false
  max_frame_displacement_px = 4
  min_track_length = 10
```

Step01：

```text
human_step01_bandpass.py
input:  frames.npy + metadata.json
output: human_filtered.npy
```

Step02：

```text
human_step02_gaussian_filter.py
input:  human_filtered.npy + metadata.json
output: human_smoothed.npy
```

Step03：

```text
human_step03_track.py
input:  human_filtered.npy + human_smoothed.npy + metadata.json
output: human_detections.csv + human_tracks.csv
```

Step04：

```text
human_step04_density_metrics.py
input:  rapid/human_tracks.csv + slow/human_tracks.csv + metadata.json
output: density PNG + human_rapid_tracks.csv + human_slow_tracks.csv + human_metrics.csv
```

当前常用 Step04 输出：

```text
human_dcm/step04_density_metrics/human_density_total.png
human_dcm/step04_density_metrics/human_density_rapid.png
human_dcm/step04_density_metrics/human_density_slow.png
human_dcm/step04_density_metrics/human_density_profile_overlay.png
human_dcm/step04_density_metrics/human_rapid_tracks.csv
human_dcm/step04_density_metrics/human_slow_tracks.csv
human_dcm/step04_density_metrics/human_metrics.csv
human_dcm/step04_density_metrics/human_summary.txt
```

`human_density_slow.png` 是 slow tracks 的轨迹点密度图，不是肾小球计数图。它是 Step05 mask 绘制的默认背景。

## Step05：Mask 绘制

当前 mask 绘制命令：

```bash
.venv/bin/python human_step05_glomeruli_count.py --mode cortex
.venv/bin/python human_step05_glomeruli_count.py --mode exclude
```

默认背景：

```text
human_dcm/step04_density_metrics/human_density_slow.png
```

默认输出：

```text
masks/cortex_mask.npy
masks/cortex_mask_overlay.png
masks/cortex_mask.log.json
masks/exclude_mask.npy
masks/exclude_mask_overlay.png
masks/exclude_mask.log.json
```

全流程样本模式要求 `all_masks/<sample_id>/` 已经包含 `cortex_mask.npy` 和
`exclude_mask.npy`。缺 mask 时应先使用 `step00_preprocess.py --mask-only` 生成或重画；
`--run-full-pipeline` 不负责画 mask，也不会在流程中重跑 Step00。

交互方式：

```text
鼠标点击 polygon 顶点
Enter 完成当前 polygon
空 Enter 保存并退出
```

## Step05：肾小球候选计数

默认运行：

```bash
.venv/bin/python human_step05_glomeruli_count.py --mode exec
```

默认输入：

```text
human_dcm/step04_density_metrics/human_slow_tracks.csv
human_dcm/step04_density_metrics/human_rapid_tracks.csv
human_dcm/step04_density_metrics/human_density_slow.png
human_dcm/step04_density_metrics/human_density_rapid.png
masks/cortex_mask.npy
masks/exclude_mask.npy
```

默认输出：

```text
human_dcm/step05_glomeruli_count/
```

核心逻辑：

```text
读取 slow tracks
计算每条 track 的 normalized distance、duration、speed、center
用 cortex/exclude/border/fast-vessel mask 过滤
在 isotropic grid 上生成 ND map 和 glomerular candidate mask
筛出肾小球相关慢速轨迹
用 DBSCAN 聚类轨迹中心
输出 final_glomeruli.csv 和诊断图
```

当前默认参数要点：

```text
glomerulus_radius_mm = 0.05
iso_spacing_mm = 0.02
fast_vessel_percentile = 99.5
fast_vessel_dilate_mm = 0.0
exclude_inside_frac_max = 0.25
dbscan_min_samples = 1
calibration_enabled = true
calibration_target_count = 450
calibration_min_count = 400
dbscan_eps scan range = 0.04-0.30 mm
```

当前 Step05 是单一候选集计数。旧版 loose/strict 双输出已移除。

关键输出：

```text
summary.json
config.json
track_metrics.csv
filtered_points.csv
per_block_counts.csv
final_glomeruli.csv
nd_map_iso.png
slow_density_overlay_cortex.png
glomerular_mask_overlay.png
fast_exclusion_overlay.png
track_filter_diagnostics.png
final_glomeruli_centers.png
glomerular_track_distribution.png
glomerular_track_distribution_on_slow_density.png
```

详细解释见 `archive/8.step05.md`。

## 健康标定和诊断模式

健康样本默认：

```bash
.venv/bin/python step00_preprocess.py \
  --kind human \
  --run-full-pipeline \
  --sample 21.0 \
  --count-mode healthy_calibration
```

每个健康样本会保存：

```text
archive/healthy_step05_runs/<sample_id>_summary.json
```

统计公共诊断参数：

```bash
.venv/bin/python step00_preprocess.py --summarize-healthy-runs
```

输出：

```text
archive/healthy_step05_runs/global_arguments.json
```

病肾/未知样本应使用固定公共 eps，不使用逐样本健康校准：

```bash
.venv/bin/python step00_preprocess.py \
  --kind human \
  --run-full-pipeline \
  --sample disease_01 \
  --count-mode diagnostic \
  --dbscan-eps-mm <healthy_common_eps>
```

单独跑 Step05 诊断模式：

```bash
.venv/bin/python human_step05_glomeruli_count.py \
  --mode exec \
  --count-mode diagnostic \
  --dbscan-eps-mm <healthy_common_eps>
```
