# 项目总览

本项目用于整理并运行肾脏 ULM/sULM 后处理流程。当前代码分为人类样例链路、小鼠链路框架、Akebia MATLAB/Python 对照代码、Step5 肾小球候选计数和交互式 mask 标注工具。

## 统一数据约定

Step 之间尽量只传结构化数据：

```text
frames.npy              float32 [T,H,W]
metadata.json           fps、像素尺寸、ROI、帧数等元数据
*_detections.csv        每行一个微泡候选点
*_tracks.csv            每行一个轨迹点
*_metrics.csv           每行一个轨迹或候选目标指标
*.png                   可视化检查图，不作为核心数值输入
```

当前 `stable_200_400` 样例来自 `human_dcm/11.0.dcm` 的源视频第 200 到 400 帧，共 201 帧。Step0 裁剪后原始处理网格为 `590 x 602`。

## Step 0：DICOM/CEUS 预处理

入口：

```bash
python step00_preprocess.py --kind human
python step00_preprocess.py --kind mouse
```

主要逻辑：

1. 读取 DICOM 像素数据和元数据。
2. 根据超声区域标签或当前规则裁剪 ROI，去掉设备界面和无关区域。
3. 彩色 CEUS 帧转换为橙黄色造影增强 score；单通道图像按灰度强度归一化。
4. 输出 `float32 [T,H,W]` 的 `frames.npy` 和 `metadata.json`。

典型输出：

```text
human_dcm/step00_preprocess/stable_200_400/frames.npy
human_dcm/step00_preprocess/stable_200_400/metadata.json
human_dcm/step00_preprocess/stable_200_400/preview_frame_000.png
```

## Human Step 1：Akebia human profile 时域处理

单 profile 入口：

```bash
python human_step01_bandpass.py --profile rapid
python human_step01_bandpass.py --profile slow
```

双 profile 入口：

```bash
python human_run_profiles.py --label stable_200_400
```

当前 Human profile 定义：

```text
Rapid:
  use_bandpass = true
  Butterworth 1 阶因果带通
  bandpass = [1, 5.5] Hz
  maxLinkingDistance = 15 px/frame
  minLength = 5 frames

Slow:
  use_bandpass = false
  不做时域带通，直接传递 Step0 帧
  maxLinkingDistance = 4 px/frame
  minLength = 10 frames
```

Rapid 对应 Akebia human 的快速 profile，用一阶 `butter + lfilter` 做因果带通。Slow 对应 Akebia human 的 `useBandpass=false`，保留原始慢变化造影增强响应。

典型输出：

```text
human_dcm/step01_bandpass/stable_200_400/rapid/human_filtered.npy
human_dcm/step01_bandpass/stable_200_400/slow/human_filtered.npy
```

## Human Step 2：Gaussian guide

入口：

```bash
python human_step02_gaussian_filter.py
```

主要逻辑：

1. 读取 Step1 输出的 `human_filtered.npy`。
2. 对每帧做二维 Gaussian smoothing，当前 `sigma=1.0`。
3. 这个平滑结果只作为局部极大值搜索 guide，不直接替代原始强度。

对应 Akebia human 的核心形式：

```text
imregionalmax(imgaussfilt(frame, sigma)) .* frame
```

当前 Python 实现中，Step2 负责 `imgaussfilt` 对应的 guide；Step3 用 guide 找峰位置，再回到 Step1 帧上取强度和做阈值。

典型输出：

```text
human_dcm/step02_gaussian_filter/stable_200_400/rapid/human_smoothed.npy
human_dcm/step02_gaussian_filter/stable_200_400/slow/human_smoothed.npy
```

## Human Step 3：微泡检测和匈牙利追踪

入口：

```bash
python human_step03_track.py --profile rapid
python human_step03_track.py --profile slow
```

主要逻辑：

1. 对每帧构建正向响应：

```text
response = max(frame, 0)
```

2. 在 Step2 的 Gaussian guide 上找局部极大值。
3. 回到 Step1 原始帧的正向响应上做阈值：

```text
threshold = mean(response) + 2.0 * std(response)
```

4. 把每帧检测点写成 `*_detections.csv`。
5. 使用匈牙利算法做 frame-to-frame tracking。
6. 按 profile 参数过滤轨迹长度、帧间最大位移和缺失帧。

注意：Step3 追出来的是所有满足 profile 参数的微泡轨迹。Slow tracks 只是“帧间位移小、持续时间较长”的轨迹，不等于肾小球轨迹。

`stable_200_400` 当前结果：

```text
Rapid:
  detections = 260991
  valid_tracks = 12764

Slow:
  detections = 200099
  valid_tracks = 3472
```

典型输出：

```text
human_dcm/step03_track/stable_200_400/rapid/human_tracks.csv
human_dcm/step03_track/stable_200_400/slow/human_tracks.csv
```

## Human Step 4：密度图和轨迹指标

入口：

```bash
python human_step04_density_metrics.py \
  --rapid-tracks human_dcm/step03_track/stable_200_400/rapid/human_tracks.csv \
  --slow-tracks human_dcm/step03_track/stable_200_400/slow/human_tracks.csv \
  --metadata human_dcm/step00_preprocess/stable_200_400/metadata.json \
  --output-dir human_dcm/step04_density_metrics/stable_200_400
```

`human_run_profiles.py --label stable_200_400` 会自动运行 Step1 到 Step4。

主要逻辑：

1. 读取 rapid 和 slow tracks。
2. 将轨迹点投影到超分辨率网格，当前 `SUPER_RES_FACTOR=4`。
3. 对每个轨迹点执行：

```text
x_sr = round(x_pixel * 4)
y_sr = round(y_pixel * 4)
density[y_sr, x_sr] += 1
```

4. 对 density 做 Gaussian blur，当前 `sigmaX=1.2 * SUPER_RES_FACTOR`。
5. 按非零像素 99 百分位归一化到 `uint8`。
6. 输出 total、rapid、slow 和 rapid/slow overlay 图。
7. 同时计算轨迹级指标，例如平均速度、normalized distance、dwell time、dispersion。

典型输出：

```text
human_dcm/step04_density_metrics/stable_200_400/human_density_total.png
human_dcm/step04_density_metrics/stable_200_400/human_density_rapid.png
human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png
human_dcm/step04_density_metrics/stable_200_400/human_density_profile_overlay.png
human_dcm/step04_density_metrics/stable_200_400/human_rapid_tracks.csv
human_dcm/step04_density_metrics/stable_200_400/human_slow_tracks.csv
human_dcm/step04_density_metrics/stable_200_400/human_metrics.csv
human_dcm/step04_density_metrics/stable_200_400/human_summary.txt
```

`human_density_slow.png` 是所有 slow tracks 的轨迹点密度图，不是肾小球计数图。它适合用来观察慢速轨迹聚集和排除伪影。

## Step 5 mask 标注

交互式脚本：

```bash
python draw_step5_masks.py \
  --image human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --output masks/cortex_mask.npy \
  --overlay masks/cortex_mask_overlay.png \
  --mode cortex

python draw_step5_masks.py \
  --image human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --output masks/exclude_mask.npy \
  --overlay masks/exclude_mask_overlay.png \
  --mode exclude
```

已打包的 macOS 可执行版：

```bash
step5/app/dist/Step5MaskDrawer/Step5MaskDrawer.exe \
  --image human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --output masks/cortex_mask.npy \
  --overlay masks/cortex_mask_overlay.png \
  --mode cortex
```

快捷键：

```text
Enter  完成当前 polygon
n      新建下一个 polygon
u      撤销上一个 polygon
s      保存 mask、overlay 和 log
q      退出
```

mask 规则：

```text
cortex_mask:
  允许 Step5 搜索肾小球候选的区域。

exclude_mask:
  手动排除伪影、图像边界、右侧竖直亮点、左下角孤立点、非肾区域等。
```

如果用 Step4 的 4 倍超分辨率 PNG 画 mask，mask shape 会是 `2360 x 2408`。Step5 内部会识别这种 4 倍图，并还原到原始轨迹坐标 `590 x 602` 后再转换到 isotropic grid。

## Step 5：基于慢速轨迹的肾小球候选计数

入口：

```bash
python human_step05_glomeruli_count.py \
  --slow-tracks human_dcm/step04_density_metrics/stable_200_400/human_slow_tracks.csv \
  --fast-tracks human_dcm/step04_density_metrics/stable_200_400/human_rapid_tracks.csv \
  --slow-density human_dcm/step04_density_metrics/stable_200_400/human_density_slow.png \
  --fast-density human_dcm/step04_density_metrics/stable_200_400/human_density_rapid.png \
  --cortex-mask masks/cortex_mask.npy \
  --exclude-mask masks/exclude_mask.npy \
  --output-dir human_dcm/step05_glomeruli_count/stable_200_400
```

主要逻辑：

1. 读取 slow tracks，兼容 `x_pixel/y_pixel/frame_id` 和 `x_px/y_px/frame` 字段。
2. 将轨迹点转换到物理坐标：

```text
x_mm = x_px * x_spacing_mm
y_mm = y_px * y_spacing_mm
```

3. 转换到 isotropic grid：

```text
x_iso = x_mm / iso_spacing_mm
y_iso = y_mm / iso_spacing_mm
```

4. 对每条 slow track 计算：

```text
path_length_mm
end_to_end_distance_mm
normalized_distance = path_length_mm / end_to_end_distance_mm
duration_sec
mean_speed_mm_s
track center
```

5. 过滤轨迹：

```text
cortex_inside_frac >= 0.5
不落入 exclude_mask
不落入 border mask
不落入 fast_vessel_mask
```

6. 用保留下来的 slow tracks 建立 high-ND map。
7. 对 ND map 做 Gaussian smoothing。
8. 在 cortex 内取默认 P90 得到 seed mask。
9. 按肾小球半径扩张 seed，得到 glomerular mask。
10. 反向筛 slow tracks：

```text
loose:
  glom_inside_frac >= 0.00
  当前按 CT 层扫切片预计约 450 个肾小球进行标定；
  loose 模式表示 cortex/exclude/fast-vessel 过滤后的候选慢速轨迹都参与分布和计数。

strict:
  glom_inside_frac >= 0.80
```

11. 对 loose/strict 轨迹中心分别用 DBSCAN 聚类：

```text
eps = 0.23 mm
min_samples = 1
```

12. 每个非噪声 cluster 作为一个候选肾小球中心。

Step5 还会用 loose/strict glomerular tracks 重新累计轨迹点，输出肾小球相关轨迹的空间分布图。这个分布图表达的是“筛出的肾小球相关轨迹在哪里”，不是只有几个候选中心点。

当前默认鼠类尺度参数：

```text
glomerulus_radius_mm = 0.05
iso_spacing_mm = 0.02
radius_iso_px = 2.5
```

典型输出：

```text
human_dcm/step05_glomeruli_count/stable_200_400/summary.json
human_dcm/step05_glomeruli_count/stable_200_400/final_glomeruli.csv
human_dcm/step05_glomeruli_count/stable_200_400/final_glomeruli_loose.csv
human_dcm/step05_glomeruli_count/stable_200_400/final_glomeruli_strict.csv
human_dcm/step05_glomeruli_count/stable_200_400/filtered_points_loose.csv
```

## 小鼠链路

当前小鼠链路只有算法框架，没有真实小鼠样例校准。

```bash
python mouse_step01_svd_filter.py
python mouse_step02_radial_symmetry_detect.py
python mouse_step03_track_reconstruct.py
```

小鼠逻辑：

1. Step1 使用 SVD 滤波抑制组织背景和低秩运动。
2. Step2 使用径向对称法做亚像素定位。
3. Step3 使用匈牙利追踪并重建密度图。

## 与 Akebia 的关系

本项目的人类链路按 Akebia human profile 改写：

```text
Rapid:
  Akebia human 一阶因果带通 [1, 5.5] Hz

Slow:
  Akebia human useBandpass=false
```

Akebia example code 主要实现 sULM 成像链路：滤波、定位、追踪、density/directivity/velocity map。论文中的肾小球计数、normalized distance glomerular mask、PDW/FWHM 等后处理，在 Akebia example 中没有完整体现；本项目的 Step5 是在现有 tracks 基础上补的候选计数后处理。
