   四、artifact mask 构建方式
   
   请实现一个明确的 artifact mask 构建函数：
   
   def build_artifact_mask(
       artifact_low: np.ndarray,
       artifact_high: np.ndarray,
       mask_source: str = "total",
       percentile: float = 70.0,
       dilate: int = 21,
       close: int = 31,
       use_band_mask: bool = True,
       top_frac: float = 0.25,
       bottom_frac: float = 0.75,
   ) -> np.ndarray:
       ...
   
   函数作用：
   根据前 120 帧生成的 artifact density，构建一个二值伪影区域 mask。
   mask=True 的位置表示“该空间区域疑似伪影，应在 target density 中被削弱或清除”。

   各参数含义：
   
   1. artifact_low
      - 前 120 帧参考轨迹中的低速密度矩阵。
      - 类型：float32 density map。
      - 来源：artifact tracks 按速度阈值分组后累计得到。
      - 注意：它不一定只代表真实低速流动，也可能包含低速伪影。
   
   2. artifact_high
      - 前 120 帧参考轨迹中的高速密度矩阵。
      - 类型：float32 density map。
      - 来源：artifact tracks 按速度阈值分组后累计得到。
      - 注意：它不一定覆盖所有高速伪影，因为伪影速度分组可能不稳定。
   
   3. mask_source
      - 指定用哪一部分 artifact density 构建 mask。
      - 可选：
        - "total"：artifact_low + artifact_high，推荐默认值。
          用所有伪影轨迹构建统一 mask，最稳。
        - "high"：只用 artifact_high。
          只适合确认高速伪影在参考段中确实稳定存在的情况。
        - "low"：只用 artifact_low。
          用于测试低速伪影对结果的影响。
        - "union"：分别从 low/high 构建 mask 后取并集。
          更严格地区分两个速度通道，但一般不如 total 简单稳定。
   
   4. percentile
      - 根据 artifact density 的非零像素分布取百分位阈值。
      - 例如 percentile=70 表示：
        artifact_total 中非零像素的第 70 百分位以上区域会被认为是伪影候选区域。
      - 值越低，mask 越大，去伪影更激进；
      - 值越高，mask 越小，去伪影更保守。
      - 当前伪影是上下带状且范围较大，所以默认 70 比 90 更合适。
   
   5. dilate
      - mask 膨胀核大小。
      - 用于扩大伪影区域，覆盖前后时段轻微空间漂移。
      - 例如 dilate=21 表示使用 21×21 kernel 做膨胀。
      - 值越大，mask 越宽，扣除越强。
      - 如果设为 0 或 1，可以视为不膨胀。

   6. close
      - mask 闭运算核大小。
      - 用于填补 mask 中的小孔、连接断裂区域。
      - 对带状伪影很重要，因为伪影可能是断断续续的点状/条状。
      - 例如 close=31 表示用较大的结构元素把断裂的伪影带连起来。
   
   7. use_band_mask
      - 是否启用人工先验带状 mask。
      - 当前你已经观察到伪影主要在图像上侧和下侧，因此建议 True。
      - True 时，会把图像上方一段和下方一段直接纳入 artifact_mask。
      - False 时，只根据 artifact density 自动生成 mask。
   
   8. top_frac
      - 顶部伪影带比例。
      - 例如 top_frac=0.25 表示图像高度前 25% 被视为顶部伪影带。
      - 如果图像高度为 H，则 y < H*0.25 的区域进入 band mask。
   
   9. bottom_frac
      - 底部伪影带起始比例。
      - 例如 bottom_frac=0.75 表示从图像高度 75% 处开始到底部都视为底部伪影带。
      - 如果图像高度为 H，则 y >= H*0.75 的区域进入 band mask。

   函数内部推荐逻辑：

   artifact_total = artifact_low + artifact_high

   根据 mask_source 选择 mask_base：

   if mask_source == "total":
       mask_base = artifact_total
   
   elif mask_source == "high":
       mask_base = artifact_high
   
   elif mask_source == "low":
       mask_base = artifact_low
   
   elif mask_source == "union":
       分别对 artifact_low 和 artifact_high 构建 mask，然后 OR

   对 mask_base 的非零像素计算阈值：

   positive = mask_base[mask_base > 0]
   threshold = np.percentile(positive, percentile)
   density_mask = mask_base >= threshold

   形态学处理：

   if close > 1:
       density_mask = cv2.morphologyEx(density_mask, cv2.MORPH_CLOSE, kernel)

   if dilate > 1:
       density_mask = cv2.dilate(density_mask, kernel)
   
   如果 use_band_mask=True：
       band_mask = zeros_like(density_mask)
       band_mask[:int(h * top_frac), :] = True
       band_mask[int(h * bottom_frac):, :] = True
       artifact_mask = density_mask OR band_mask
   
   否则：
       artifact_mask = density_mask

   返回 artifact_mask。

   --artifact-mask-close
   type=int
   default=31
   含义：
       mask 闭运算核大小。
       用于连接断裂的伪影区域，尤其适合带状伪影。
   
   --use-band-mask
   action="store_true"
   default=True
   含义：
       是否启用上下带状伪影先验。
       当前应默认启用。
   
   --no-band-mask
   action="store_false"
   dest="use_band_mask"
   含义：
       关闭上下带状 mask，仅使用 artifact density 自动生成 mask。
       用于调试。
   
   --artifact-band-top
   type=float
   default=0.25
   含义：
       顶部伪影带的高度比例。
       0.25 表示上方 25% 高度区域进入 mask。
   
   --artifact-band-bottom
   type=float
   default=0.75
   含义：
       底部伪影带起始位置。
       0.75 表示从图像高度 75% 到底部进入 mask。
   
   --low-keep-ratio
   type=float
   default=0.2
   含义：
       mask 区域内低速密度保留比例。
       0.2 表示保留 20%，削弱 80%。
   
   --high-keep-ratio
   type=float
   default=0.0
   含义：
       mask 区域内高速密度保留比例。
       0.0 表示直接清零。
       当前高速大部分疑似伪影，因此默认 0.0。
   
   --save-density-npy
   action="store_true"
   default=True
   含义：
       是否保存扣除前后的 float32 density matrix。
       建议默认 True。
   
   --fixed-scale-preview
   action="store_true"
   default=True
   含义：
       是否额外生成同尺度 before/after 对比图。
       建议默认 True，用于排除 PNG 独立归一化造成的误判。
