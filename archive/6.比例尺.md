右侧造影窗视野大约：45~50 mm 宽 × 28 mm 深

一个肾小球的量级很小，通常按 **0.1–0.2 mm 直径** 来理解。

| 方向                   | 0.1 mm / 像素尺寸    | 0.2 mm / 像素尺寸    |
| ---------------------- | -------------------- | -------------------- |
| **水平方向**           | 0.1 / 0.08 ≈ 1.3 px  | 0.2 / 0.08 ≈ 2.5 px  |
| **垂直方向**           | 0.1 / 0.047 ≈ 2.1 px | 0.2 / 0.047 ≈ 4.2 px |
| **用 metadata 统一值** | 0.1 / 0.064 ≈ 1.6 px | 0.2 / 0.064 ≈ 3.1 px |

### 结论

一个肾小球在图像中大约占 **1.5 ~ 4 个像素直径**，也就是 **约 2~15 个像素的面积**。非常小。
